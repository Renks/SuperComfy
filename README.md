# QUICK START
1. git clone this repo and cd to it
2. make sure node version is: v26.13.1
3. make sure npm version is: 11.20.0
4. run `npm install`
5. run `npm install lucide-react tailwindcss @tailwindcss/vite`
6. run `npm run dev`
7. open `http://localhost:5173/` in browser

Note: UI is designed for phone screens only.
